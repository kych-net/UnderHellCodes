# 元素工具 — 地狱之下世界观元素管理 CLI

管理 `文档/地狱之下.typ` 等源文件中的**元素**(核心概念 id)与 `文档/元素系统.csv`。

## 命令

```bash
python3 元素工具.py 扫描              # 查找源文件中所有元素,标注缺失的
python3 元素工具.py 补全              # 把未收录(缺失)的元素追加到 元素系统.csv
python3 元素工具.py 清理              # 查找 CSV 中存在、但文档已删除(不再引用)的元素
python3 元素工具.py 改名 旧id 新id     # 重命名元素:同步文档引用/静态标签/引用,并更新 CSV
```

默认：
- 文档目录：仓库根 `文档/`（递归扫描所有 `.typ`，含 `内容/` 子目录）
- CSV：仓库根 `文档/元素系统.csv`

可用 `--dir 路径`、`--csv 路径` 覆盖。

## 说明

- **扫描**：识别 `#元素("名")`、`#元素[名]`、`#设定元素("名")`、`#设定元素[名]`、
  `#设定元素(level: n)[名]` 五种引用形式，提取概念 id 并去重。
- **补全**：仅追加在文档中出现、但 CSV 缺失的行，格式 `id,默认,别名,academic`（其余列留空）。
- **清理**：反向核对 CSV 中仍存在、但文档已不再引用的元素（孤儿项），便于从 CSV 删除。
- **改名**：在源文件中替换上述元素引用、静态标签 `<旧id>` 与交叉引用 `@旧id`，
  并把 CSV 中等于旧 id 的单元格更新为新 id。
