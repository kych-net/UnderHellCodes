# 地狱之下程序

地狱之下(UnderHell)项目的各类工具程序(UnderHellCodes)。

## 工具

| 目录 | 说明 |
|------|------|
| `地图生成器` / `地图工具` | 地图生成器(cli + GUI 子模块) |
| `元素工具` | 维护文档元素与 `元素系统.csv` 的 CLI(扫描 / 补全 / 清理 / 改名) |
| `todo工具` | 查找源文件中所有 `#TODO` 的 CLI |
| `排版工具` | 按附录规范检查、修复文档排版的 CLI |
| `脚本` | 各类辅助脚本(如图片去背景) |
| `网站` | 网页版子模块 |

各工具详细说明见各自目录下的 `README.md`。

## 组织结构

各子模块是独立 Git 仓库(如 `地图工具`、`网站`),通过 `.gitmodules` 引用。改代码后需在对应子模块内 commit/push,再更新本仓库的子模块指针。
