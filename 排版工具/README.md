# 排版工具 — 按附录规范检查/修复文档排版

依据《文档/内容/附录.typ》排版规范,对 `文档/**/*.typ` 进行检查与自动修复。

## 用法

```bash
python3 排版工具.py 检查                # 检查不符合规范之处
python3 排版工具.py 检查 --dir 路径       # 指定目录
python3 排版工具.py 检查 --include 怪动   # 仅检查文件名含"怪动"的
python3 排版工具.py 修复                # 自动修复有把握的问题
```

## 检查项(附录规范)

| 检查项 | 说明 |
|---|---|
| 全角标点 | ，、：；（）“”‘’—— 一律半角(顿号 → 逗号) |
| 称呼 | 一律用 `它`,禁用 `她/他` |
| 温度单位 | 用 K,不用 `°C`/`℃` |
| 括注 | `(…中文…)` 应移除括号改斜体(仅提示,不自动改) |
| 中文字符间空格 | 两个字之间不要空格 |
| 正文标点后空格 | 正文标点后不加空格(代码中不变) |
| 万级大数 | 万级及以上改为科学计数法 |

## 修复范围

自动修复:
- 全角标点 → 半角
- 温度 `°C/℃` → `K`(`K = °C + 273.15`,取整)
- 删除正文标点后的空格(代码中不变)
- 中文字符间的空格

**不自动改**(仅检查):
- 括注 `(…)` → 斜体(易误伤 `表格(...)`、`csv(...)` 等代码)
- 称呼 `她/他`(只提示,不自动替换)

## 说明

- 规范文件 `内容/附录.typ` 自身在修复时跳过(其全角是规范示例)。
- 检查会自动跳过代码行(`let`/`import`/`table(`/`#表格(`/`graph` 等),减少误报。
- 仓库根定位:源码位置 → `UNDERHELL_ROOT` → 当前目录;也可用 `--dir` 指定。
